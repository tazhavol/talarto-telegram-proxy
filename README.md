# پروکسی تلگرام تالارتو

این یک پروژه‌ی خیلی ساده‌ی Vercel است که فقط یک کار انجام می‌دهد: هر
درخواستی که به آن برسد را عیناً به `api.telegram.org` می‌فرستد و جواب را
برمی‌گرداند — چون سرورهای Vercel خارج از ایران هستند، این کار محدودیت
دسترسی مستقیم ایران به تلگرام را دور می‌زند.

هیچ چیز دیگری در این پروژه نیست؛ هیچ صفحه‌ی وب، هیچ رابط کاربری. فقط
همین یک تابع.

راهنمای کامل نصب و اتصال به سایت talarto.ir در پیام همراه این پروژه است.
